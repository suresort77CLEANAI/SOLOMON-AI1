## 1막. 고객 여정 시리즈 (앱의 기능이 태어나는 이야기)

### EP.1 "인천공항, 신호가 없다" — D-Day
**장면**: 린이 입국장을 나서자 휴대폰은 '서비스 없음'. 공항 통신사 부스엔 긴 줄, 영어 안내판엔 한 달 7만 원짜리 요금제. 기숙사 주소를 찾으려면 데이터가 필요한데… 옆 친구가 보여준 QR 하나: "출국 전에 세틀에서 신청하면 공항 도착하자마자 유심이 켜져."
**인사이트**: 문제는 '입국 후'가 아니라 **입국 전**에 시작된다 → 고객 획득 시점을 출국 전으로 당긴다.
**틈새 상품**: 출국 전 예약형 **선불 유심/eSIM → 입국 후 알뜰폰 후불로 전환** (2단 개통 = 수수료 2회)
**수익**: 선불 유심 판매 마진 + 알뜰폰 개통 수수료 [건당 수만 원 가정]
**앱 화면**: "출국 전 체크인" — 국가·입국일·도착 공항 입력 → eSIM QR 또는 공항 수령
**Manus 프롬프트**
```
'출국 전 체크인' 페이지를 추가해줘. 입력: 국적, 입국 예정일, 도착 공항(ICN/GMP/PUS/CJU), 체류 유형.
결과: 'D-Day 키트' 카드(eSIM 또는 유심 수령 안내)와 '입국 후 30일 일정표'를 자동 생성.
입국일 기준 D-3에 리마인드 이메일 예약. 5개 언어 지원.
```

### EP.2 "엄마에게 첫 송금" — D+3
**장면**: 첫 아르바이트비를 받은 린. 은행 창구 직원은 빠른 한국어로 서류를 요구하고, 송금 수수료는 생각보다 크다. 세틀 버디 '투이 선배'가 베트남어로 메시지: "앱 3개 수수료·환율 비교해 놨어. 너는 이게 제일 싸."
**인사이트**: 외국인의 **반복 구매 1위는 송금** → 매달 돌아오는 재방문 이유. 아정당엔 없는 축.
**틈새 상품**: **해외송금 비교표**(국가별 수수료·환율·도착시간) + 제휴 송금 앱 가입 CPA + 첫 송금 수수료 지원
**수익**: 제휴 CPA [건당 수천~수만 원 가정], 장기적으로 송금액 연동 제휴
**앱 화면**: 송금 계산기 — "100만 원 보내면 엄마가 받는 돈" 비교
**Manus 프롬프트**
```
'송금 비교' 페이지: 보낼 금액(KRW)과 받는 국가를 입력하면 관리자에 등록된 제휴 송금사별
수수료·적용 환율·예상 수령액·도착 시간을 카드로 정렬(수령액 큰 순). 각 카드에 '가입하고 첫 송금 혜택' 버튼(제휴 링크, 클릭 추적).
관리자에서 송금사·수수료·환율 수동 업데이트 가능하게. 하단에 '정보 제공용, 실제 조건은 송금사 기준' 고지.
```

### EP.3 "원룸의 와이파이" — D+7
**장면**: 기숙사를 나와 원룸으로 옮긴 린과 룸메이트. 집주인은 "인터넷은 알아서 해요." 통신사 홈페이지는 약정·결합·위약금 용어로 가득. 세틀 앱에 '1년 체류'라고 입력하자 약정 없는 상품과 3년 약정 + 사은품 상품이 나란히, **"1년 뒤 귀국하면 위약금 OO원"**까지 계산돼 나온다.
**인사이트**: 외국인은 **체류 기간이 정해져 있다** → 아정당식 '3년 약정 최대 사은품'이 오히려 함정. **'귀국일 기준 손익 계산'** 이 차별화 무기.
**틈새 상품**: 체류기간 맞춤 인터넷(단기 무약정 / 장기 약정+사은품), **룸메이트 분할결제 안내**
**수익**: 인터넷 판매점 수수료 [건당 수십만 원 가정] − 환원 사은품
**앱 화면**: "귀국일 입력 → 총비용 비교" 그래프
**Manus 프롬프트**
```
'인터넷 맞춤 찾기': 입력(예상 귀국일, 거주 형태, 동거 인원). 상품별로 '귀국일까지 총비용 = 월요금×개월+설치비+위약금−사은품'을 계산해
총비용 낮은 순으로 보여주고, 막대그래프로 비교. 위약금이 생기는 상품엔 빨간 경고 배지. 상담 신청 버튼 연결.
```

### EP.4 "병원비 영수증" — D+14
**장면**: 공장에서 손을 다친 아지즈. 건강보험은 있는데 비급여 치료비가 따로 나왔다. 동료가 말한다. "보험 하나 있었으면 됐는데." 세틀 앱의 '안전 체크'에서 그는 자신이 건강보험만 있고 상해 보장이 비어 있다는 걸 처음 안다.
**인사이트**: 보험은 '팔면' 규제, '**빈칸을 보여주면**' 정보 → 직접 권유 대신 진단 + 등록된 대리점 연결.
**틈새 상품**: 외국인 보장 공백 **자가진단 체크리스트** → 등록 보험대리점(GA) 상담 연결(리드 제휴)
**수익**: 리드 제휴 수수료 [가정]. ⚠️ 직접 모집·권유 금지(02 문서 2-4)
**앱 화면**: 4문항 진단 → "당신의 보장 지도"(채워진 칸/빈칸)
**Manus 프롬프트**
```
'안전 체크' 진단: 4문항(건강보험 가입 여부, 직업 위험도, 가족 동반, 체류 기간) → 보장 지도(건강/상해/실손/귀국 시) 칸을 색으로 표시.
빈칸에는 '전문 상담 받기'만 노출(상품명·보험료 노출 금지). 신청 시 '등록 보험대리점 OOO에 정보 제공' 별도 동의 필수.
```

### EP.5 "집이 생겼다, 텅 빈 집이" — D+21
**장면**: 마리아는 남편과 신혼집으로 이사. 정수기·세탁기·공기청정기가 필요한데 렌탈 계약서는 한국어 20쪽. 세틀의 '이사 패키지'는 용달 + 인터넷 이전 + 렌탈 3종을 **한 번의 상담**으로 묶고, 계약서 핵심 7줄을 따갈로그어로 요약해 준다.
**인사이트**: 아정당의 강점(교차판매)을 그대로 쓰되 **'번역된 계약 요약'** 이 신뢰를 산다. 이 순간 고객당 상품 수가 1 → 4로 뛴다.
**틈새 상품**: **이사 묶음 패키지** (이사 + 인터넷 이전 + 렌탈 + 중고가전), 귀국자 중고가전 매입 → 신규 입국자 판매(순환)
**수익**: 렌탈 수수료 + 이사 리드 + 중고 중개 마진 [가정]
**앱 화면**: 패키지 장바구니 + "계약서 요약 받기"
**Manus 프롬프트**
```
'이사 패키지 빌더': 이사 날짜·지역 입력 후 이사/인터넷 이전/렌탈(정수기·공기청정기·세탁기)/중고가전을 체크박스로 담으면
예상 혜택 합계를 실시간 표시하고 한 번에 상담 신청. 신청 상세에 '계약서 요약 요청' 옵션(관리자가 다국어 요약 업로드 → 고객 마이페이지에 표시).
'귀국 전 중고가전 팔기' 폼도 만들고, 매입 목록을 '중고가전' 카테고리에 노출.
```

### EP.6 "이제 내가 선배" — D+30
**장면**: 한 달 뒤 린은 새로 오는 후배에게 자기 추천 링크를 보낸다. 후배가 유심을 개통하자 린의 앱에 "+10,000원". 학기말, 린은 베트남 유학생회 '세틀 버디'가 된다.
**인사이트**: 외국인 커뮤니티는 **국적별로 촘촘하고 신뢰가 강하다** → 광고비 대신 **선배 네트워크가 CAC를 낮춘다**. 아정당이 TV 광고로 산 것을 우리는 사람으로 산다.
**틈새 상품**: 추천 적립 + **버디(파트너) 프로그램** — 매출 일부 공유, 명함·QR 키트 제공
**수익 구조 변화**: CAC ↓, 고객당 상품 수 ↑
**앱 화면**: 마이페이지 '내 추천', 버디 대시보드
**Manus 프롬프트**: 03 문서 STEP 5 그대로 사용 + 아래 추가
```
버디 등급(Bronze/Silver/Gold: 월 전환 5/20/50건)과 등급별 정산 비율을 관리자에서 설정.
버디 전용 다운로드 키트(국가별 언어 포스터 PDF, 개인 QR) 페이지 추가.
```

## 2막. 창업 스토리 시리즈 (사업 전략이 펼쳐지는 이야기)

### EP.7 "시작: 제휴처 3곳과 랜딩 한 장" — 0→1 (1~2개월)
**장면**: 노트북 하나, Manus 프로젝트 하나. 첫 주에 알뜰폰 판매점·인터넷 판매점·송금 앱 세 곳에 전화를 돌린다. 둘은 거절, 하나는 "건당 수수료 표 보내드릴게요."
**전략**: 상품은 적게, 언어는 많게. **유심 + 인터넷 + 송금 3종만** 먼저. 혜택 금액은 제휴 확정 전엔 '예시'로.
**목표 지표**: 신청 100건, 개통 전환율 30%+
**할 일**: 03 문서 STEP 0~3 + EP.1~3 프롬프트

### EP.8 "첫 학기: 한 학교를 점령하라" — 1→10 (3~6개월)
**장면**: 2월 말 입학 시즌. 한 대학 국제처와 '신입 유학생 웰컴 키트'에 세틀 QR을 넣기로 했다. 오리엔테이션 날, 강당 뒤 테이블에서 버디 3명이 직접 개통을 돕는다.
**전략**: **한 도시·한 학교·한 국적부터 독점적으로**(베트남 유학생 → 확장). 오프라인 '개통 데이' 이벤트.
**목표 지표**: 고객당 상품 수 2.0, 추천 유입 비중 30%
**할 일**: EP.4~6 프롬프트, AI 상담(03 STEP 4)

### EP.9 "B2B의 문이 열리다" — 10→100 (6~12개월)
**장면**: 공장 인사담당자가 연락해 온다. "베트남·우즈벡 근로자 20명이 다음 달 들어오는데, 휴대폰이랑 송금 안내를 단체로 해줄 수 있나요?"
**전략**: **기관 고객(B2B2C)** — 대학 국제처, 외국인 고용 사업장, 송출·인력 업체에 '입국 패키지' 제공. 한 번 계약으로 매년 반복 유입.
**틈새 상품**: 단체 입국 키트(단체 개통·송금 교육·안전 체크), 기관 대시보드
**수익**: 건당 수수료 × 단체 인원 + 기관 운영비(선택)
**Manus 프롬프트**
```
'기관 파트너' 기능: 기관 계정이 입국 예정자 명단(CSV)을 올리면 각자에게 언어별 초대 링크를 발송하고,
기관 대시보드에서 인원별 진행 상태(유심/송금/보험 체크)를 볼 수 있게. 개인정보는 기관에 '완료 여부'만 표시.
```

### EP.10 "외국인의 아정당" — 100→ (1~2년)
**장면**: 첫 30일을 함께한 고객이 3년째 앱을 쓴다. 비자 연장, 이직, 결혼, 귀국까지. 앱 첫 화면 문구가 바뀐다. `From Day 1 to Your Last Day in Korea.`
**전략**: 정착 30일 → **체류 전 생애**로 확장(이직·비자연장 알림, 귀국 정산 패키지: 해지·중고판매·보험 정리). 데이터로 국적별 수요 예측 → 공급사 협상력 확보.
**출구 시나리오**: 아정당처럼 생활 플랫폼·통신 그룹·핀테크(송금사)의 인수 대상 [가능성, 보장 아님]
