# 5. 집중안 (최종) — "바꿀때" : 인터넷 약정 끝난 집에 현금을

> 기존 01~04는 참고용. **지금부터는 이 문서 하나로 진행.** 기준일 2026-11-12 · 금액은 [가정치]

## 한 줄 사업
**인터넷 약정이 끝났는데 그냥 쓰는 집을 찾아서, 갈아타게 하고, 현금 사은품을 준다.**

## 왜 이것인가
| 기준 | 판단 |
|------|------|
| 대중적 | 집집마다 인터넷이 있고, 대부분 3년 약정 → **누구나 3년마다 한 번** 해당 |
| 단순 | 상품 1개(인터넷+TV). 설명 필요 없음: "약정 끝? 바꾸면 돈 받음" |
| 돈이 됨 | 아정당 사은품 중 금액이 가장 큰 축이 인터넷(캡처: "인터넷 사은품 52만원") → 수수료도 가장 큼 [추정] |
| 틈새 | 아정당은 '모든 생활 서비스'. 우리는 **'약정 만료 고객' 한 순간만** 판다 |

## 스토리 (3장면, 끝)
1. **모름** — "우리 집 인터넷, 언제 가입했더라?" 약정 끝난 지 1년째, 요금은 그대로.
2. **앎** — 바꿀때에 가입 시기만 입력 → "약정 끝났어요. 지금 바꾸면 현금 최대 ○○만원."
3. **받음** — 상담 1번, 설치 1번, 통장에 입금 알림. "3년 뒤에도 알려드릴게요."

## 수익 · 비용 (1건 기준, [가정])
| 항목 | 금액 |
|------|------|
| 통신 판매 수수료 (인터넷+TV) | +[60만 원] |
| 고객 현금 사은품 | −[40만 원] |
| 광고·상담비 | −[10만 원] |
| **건당 남는 돈** | **+[10만 원]** |
| 월 100건 개통 시 | 월 [1,000만 원] |

> 실제 수수료는 제휴 판매점 단가표로 반드시 갱신. 사은품은 남는 돈 확인 후 결정.

## 진행 순서 (30일)
| 주차 | 할 일 | 완료 기준 |
|------|------|----------|
| 1주 | 인터넷 판매점(사전승낙 보유) 1곳 제휴, 수수료표 받기 | 단가표 확보 |
| 1주 | Manus로 앱 제작 (아래 프롬프트 1개) | 링크 동작 |
| 2주 | 지인·동네 커뮤니티·당근 등에 "약정 확인" 링크 배포 | 신청 30건 |
| 3~4주 | 신청 → 판매점 전달 → 개통 → 사은품 지급 | 개통 10건, 지급 완료 |

## Manus 프롬프트 (이것 하나만 붙여넣기)
```
모바일 웹앱 '바꿀때'를 만들어줘. 목적: 인터넷 약정이 끝난 가정이 통신사를 바꾸고 현금 사은품을 받게 하는 상담 신청 앱.
디자인: 흰 배경, 파란 포인트, 큰 글씨, 한국어.

[홈]
- 큰 문구: "인터넷 약정 끝났는데 그냥 쓰고 계세요?" / "바꾸면 현금 최대 ○○만원"
- 버튼: "내 약정 확인하기" (하단 고정)
- 입금 알림 예시 카드 3개 ("인터넷 사은품 ○○만원 입금"), 신청 건수 숫자(관리자 수정)
- "혜택이 약속보다 적으면 차액 보상" 문구, 자주 묻는 질문 5개

[약정 확인] 3문항
1) 현재 통신사(KT/SK/LG/기타) 2) 가입 시기(년·월) 3) 사용 중(인터넷만/인터넷+TV/휴대폰 결합)
→ 결과: 약정 만료됨이면 "지금 바꾸면 최대 ○○만원", 남았으면 "만료 ○개월 남음 – 만료 1달 전 알려드릴게요"

[신청] 이름, 전화번호, 희망 상담 시간
동의(분리): [필수] 개인정보 수집·이용, [필수] 상담 판매점 제3자 제공, [선택] 약정 만료 알림 수신

[관리자 /admin] 비밀번호 로그인
- 신청 목록: 상태(신규/상담중/개통완료/사은품지급/취소), 메모, CSV 다운로드
- 약정 남은 신청자는 만료 1달 전 알림 대상 목록으로 자동 분류
- 홈 문구·금액·숫자 수정
신청 들어오면 관리자에게 이메일 알림.
```

## 꼭 지킬 것 3가지
1. 직접 개통하지 말고 **사전승낙 받은 판매점과 제휴**(우리는 상담 신청 연결)
2. "최대 ○○만원"에는 **조건 각주** (상품·약정별 상이)
3. 제휴 확정 전 금액은 **'예시'** 표기
