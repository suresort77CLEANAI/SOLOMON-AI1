# 1. 아정당 해부 (Teardown)

## 1-1. 핵심 요약
- **정체**: 인터넷·TV·휴대폰·가전렌탈·카드·이사·청소·부동산·인테리어·상조·보험·자동차·쇼핑적립 등 **12개 생활 서비스 비교·가입 중개 플랫폼** (+ 사업자용 '매장패키지')
- **돈 버는 방식**: 통신사/렌탈사/카드사 등 공급사가 주는 **판매수수료(판매장려금)** 를 받고, 그중 일부를 고객에게 **현금 사은품**으로 돌려줌 → "가입하면 돈을 준다"가 곧 마케팅
- **성장 속도** [확인]: 매출 184억(2022) → 513억(2023) → 1,191억(2024) → **2,196억(2025)**, 영업이익 16 → 32 → 109 → **166억** (영업이익률 약 7.6%)
- **자본 이벤트** [확인 필요]: 2026-01 커넥트웨이브가 지분 51%를 약 1,500억 원에 인수, 기업가치 약 3,000억 원이라는 보도(브런치 글 인용). 회사 측은 "외부 투자 없이 성장"을 강조 → 출처 간 표현 차이 있음

## 1-2. 수익 · 비용 구조
```
공급사(KT·SKB·LGU+, 렌탈사, 카드사, 상조, 보험…)
        │ 판매수수료 (건당 수십만 원 단위, 상품·시기별 변동) [추정]
        ▼
     아정당 ──── 사은품(현금) 환원 ───▶ 고객
        │
        ├─ 광고비 (TV CF·유명 배우 모델·퍼포먼스)  ← 최대 비용
        ├─ 상담 인력 (콜센터, 월 17.5만 건 상담)
        └─ 사은품 지급분
```
| 항목 | 성격 | 레버 |
|------|------|------|
| 매출 | 건당 수수료 × 개통 건수 | 상담→개통 전환율, 카테고리 교차판매 |
| 원가 | 사은품 환원 | "최대 지원금"을 내세우되 마진 유지 |
| 판관비 | 광고·상담 인건비 | 브랜드 인지도↑ → CAC↓ |
| **핵심 지표** | **고객 1명당 가입 상품 수(교차판매)** | 인터넷 → 렌탈 → 카드 → 이사 → 상조 |

> 해석: 매출 성장 대비 영업이익률이 한 자릿수 → **광고로 수요를 사오는 구조**. 후발주자가 같은 판(통신 일반)에서 광고비 경쟁하면 진다. → **틈새로 가야 하는 이유**.

## 1-4. 아정당의 약점 = 틈새 진입점
1. **내국인·한국어 전용** — 외국인 고객 경험 사실상 없음 (화면상 다국어 미확인)
2. **범용 카테고리 경쟁** — 광고비 싸움, 브랜드 대체 어려움
3. **상담 의존** — 인건비 비례 성장 → AI 상담으로 원가 우위 가능
4. **이벤트(생애 사건) 단위 설계가 약함** — 카테고리별 나열, "이사/입국/개업" 같은 순간 단위 패키지는 일부만
