# 3. Manus 개발 프롬프트 팩

> 사용법: Manus에 **단계별로 한 개씩** 붙여 넣고, 각 단계 끝에 결과 URL로 검수 후 다음 단계 진행.
> 한 번에 다 시키면 품질이 떨어지고 수정이 어려움. [ ] 안은 직접 채울 값.

## STEP 0. 프로젝트 컨텍스트 (최초 1회)
```
너는 한국 생활서비스 중개 플랫폼을 만드는 시니어 풀스택 개발자다.
벤치마크: 한국의 '아정당'(인터넷·휴대폰·렌탈 가입 시 현금 사은품을 주는 비교·상담 플랫폼).
우리 서비스: 한국에 새로 온 외국인을 위한 '정착 원스톱' 플랫폼. 이름: [SETTLE.KR]
타깃: 유학생, 외국인 근로자, 결혼이민자.
지원 언어: 영어(기본), 한국어, 베트남어, 중국어(간체), 우즈베크어. 언어 전환 토글 필수.
핵심 행동: 방문자가 '내 정착 혜택 확인' 버튼 → 3단계 설문 → 상담 신청(리드) 제출.
기술: 모바일 우선 반응형 웹앱. 데이터 저장 + 관리자 페이지 필요.
톤: 신뢰감 있는 파란색 계열, 큰 글씨, 단순한 카드 UI.
이 컨텍스트를 기억하고 다음 지시를 기다려.
```

## STEP 1. 랜딩 페이지
```
홈 화면을 만들어줘. 위에서 아래 순서:
1) 상단 롤링 띠배너 3개 (예: "유심 개통하면 [3만원] 캐시백", "인터넷 가입 최대 [40만원]", "친구 추천 시 [1만원]") — 닫기 버튼 포함
2) 히어로: "Settle in Korea, the easy way" + 단어가 2초마다 바뀌는 문구 "Better [SIM / Internet / Money transfer / Moving] in Korea", CTA 버튼 '내 정착 혜택 확인'
3) 하단 고정 플로팅 CTA '내 정착 혜택 확인' (스크롤해도 유지)
4) 혜택 입금 알림 목업 카드 3개(예: "Internet gift paid: ₩400,000")
5) 사회적 증거 숫자 블록: 누적 상담 [N]건, 국적 [N]개국 (관리자에서 수정 가능)
6) 서비스 그리드 8개: 유심/알뜰폰, 인터넷·TV, 해외송금, 보험, 가전렌탈, 중고가전, 이사, 원룸찾기(제휴)
7) '도착 후 30일 체크리스트' 섹션: D+0 유심, D+3 은행·송금, D+7 인터넷, D+14 보험, D+30 외국인등록 후 추가 혜택
8) 신뢰 섹션: "혜택이 약속보다 적으면 차액 보상" + 지원금 지급 내역(마스킹된 이름·국적·금액·날짜) 리스트
9) FAQ 아코디언, 푸터(사업자 정보 placeholder, 개인정보처리방침 링크)
10) 우측 하단 채팅 버튼
하단 탭바: 홈 / 맞춤상품찾기 / Q&A / 마이페이지.
모든 텍스트는 5개 언어 번역 파일로 분리해.
```

## STEP 2. 맞춤 설문 → 리드 수집
```
'내 정착 혜택 확인' 클릭 시 3단계 설문:
Q1 체류 유형(유학생/근로자/결혼이민/기타), Q2 외국인등록증 보유 여부, Q3 필요한 서비스(복수선택)
→ 결과 화면: 선택에 맞는 상품 카드와 '예상 혜택 합계 최대 ₩[X]' 표시
   (외국인등록증 미보유 시 여권으로 가능한 상품만 노출하는 규칙 적용)
→ 상담 신청 폼: 이름, 연락처(국가번호 선택), 메신저(WhatsApp/Zalo/WeChat/KakaoTalk/Telegram)+ID, 희망 언어, 거주 지역
→ 동의 체크박스 3개(분리): [필수] 개인정보 수집·이용, [필수] 제휴사 제3자 제공(제휴사 목록 표시), [선택] 마케팅 수신
   각 동의문은 선택 언어로 표시.
제출 시 DB 저장 + 관리자에게 이메일 알림. 완료 화면에 신청번호와 '친구 초대 링크' 표시.
```

## STEP 3. 관리자 페이지
```
/admin (비밀번호 로그인)에 다음 기능:
- 리드 목록: 상태(신규/상담중/개통완료/혜택지급완료/취소), 담당자, 메모, 필터·검색, CSV 다운로드
- 상품 관리: 카테고리, 상품명, 제휴사, 우리 수수료(내부용), 고객 환원 혜택, 노출 언어, 필요 서류 조건(여권/ARC)
- 지급 내역 관리: 공개 여부 체크 시 홈 '지급 내역'에 마스킹 표시
- 대시보드: 일별 리드 수, 상태별 전환율, 고객당 개통 상품 수, 상품별 예상 마진(수수료−환원)
- 배너·숫자 블록 문구 수정
```

## STEP 4. AI 상담 챗봇
```
채팅 버튼에 다국어 AI 상담을 붙여줘.
- 상품 DB와 FAQ만 근거로 답하고, 모르면 "상담원 연결"로 넘겨 리드 생성
- 금지: 보험·카드 상품 직접 권유/가입 처리, 비자·법률 확정 답변 (안내 문구로 대체)
- 대화 언어 자동 감지, 대화 로그는 관리자 리드 상세에 첨부
```

## STEP 5. 교차판매 자동화 & 추천 프로그램
```
- 리드 상태가 '개통완료'가 되면 D+7, D+14, D+30에 다음 추천 상품 메시지(이메일/메신저 링크) 자동 발송 예약
- 추천인 코드: 추천으로 개통 완료 시 추천인에게 [₩10,000] 적립, 마이페이지에서 적립 내역 확인
- 파트너(유학생 대표) 계정: 본인 링크 유입·전환 수 조회
```

## STEP 6. 마무리 점검
```
아래를 점검하고 문제를 고친 뒤 결과를 표로 보고해:
모바일 360px 레이아웃, 5개 언어 누락 키, 폼 유효성(전화번호 국가별), 관리자 접근 제어,
개인정보처리방침 페이지 존재, 페이지 로딩 속도, 메타태그/OG 이미지, Google Analytics 이벤트(설문 시작·완료·신청).
```

## 검수 체크리스트 (사람이 직접)
- [ ] 휴대폰으로 실제 신청 1건 → 관리자 도착·알림 확인
- [ ] 각 언어 원어민 1명에게 문구 검수 (기계번역 오류는 신뢰 붕괴)
- [ ] "최대 OO원" 문구마다 조건 각주 존재
- [ ] 제3자 제공 동의에 실제 제휴사 이름 기재
- [ ] 관리자 비밀번호·DB 백업 설정
- [ ] 제휴 계약 전에는 혜택 금액을 '예시'로 표기

## Manus 활용 팁
- 결과물이 마음에 안 들면 **"STEP 1의 3번만 수정"**처럼 범위를 좁혀 지시
- 화면 캡처(아정당 캡처 포함)를 첨부해 "이 레이아웃 구조 참고, 디자인·문구·로고는 우리 것으로"라고 지시 — **아정당의 로고·모델 사진·문구를 그대로 복제하지 말 것**(상표·저작권)
- 각 STEP 완료 후 코드/프로젝트를 내보내기(Export) 해 백업 (Manus 외부 이전 대비)
