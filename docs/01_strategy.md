# 1. 사업 개요 · 경쟁 전략

## 1-1. 핵심 요약
- **상품**: 냉동 살오징어를 해동·손질·반건조한 '준치' (구이용 / 포장 소매용)
- **채널**: ① 준치펍 매장(구이+맥주·음료, 테이크아웃 컵) ② 소매 포장(진공 1~3미, 선물 박스)
- **입지**: 월정리 해변·카페거리 — 관광객 유동 많음, 체류시간 짧음(사진·산책 위주) → **"빨리, 들고 다니며, 사진 찍히는"** 상품이 맞음
- **목표 객단가(가정)**: 매장 15,000~20,000원 / 소매 20,000~35,000원

## 1-2. 시장 · 경쟁 현황 (확인된 사실 + 추정 구분)
| 구분 | 내용 | 신뢰도 |
|------|------|--------|
| '준치' 수요 | 제주에서 반건조 오징어를 '준치'로 부르며, 성산 **목화휴게소**가 맥반석 준치구이+맥주로 유명(2022년 블로그 기준 1마리 7,000원, 현금 위주, TV 방송 노출) | 확인 (출처: 블로그 2022-08) |
| 기타 경쟁점 | 한경면 고산리 등 서쪽에도 반건조 오징어 전문점 존재 | 확인 |
| 월정리 상권 | 서핑·카페거리 중심 관광 상권, 식음료 매장 다수 | 확인 (위키백과) |
| 월정리 내 준치 전문점 | **명확한 강자 미확인** → 현장 조사 필요 | 추정 |
| 오징어 원물가 | 국내 살오징어 어획량 감소로 2023~2025년 가격 강세 추세 | 추정 (시세 직접 확인 필요) |

> ⚠️ 오픈 전 반드시: 월정리 반경 1km 내 오징어/건어물/주점 메뉴·가격 실사(사진 기록).

## 1-3. 포지셔닝
```
            레트로·저가 ───────────────── 감성·프리미엄
                │ 목화휴게소(성산)              │
  매장 체험형 ──┤                               ├── ★ 준치펍(월정)
                │ 시장 건어물 가게              │    "바다 보며 준치 한 마리 + 맥주"
  포장 판매형 ──┤ 공항 기념품(완제품 매입)      ├── ★ 준치펍 선물박스
```
- **USP**: "월정 바다 앞, 직접 말린 준치 + 제주 소스 + 들고 다니는 준치컵"
- **슬로건 후보**: `바다에서 말린 한 마리` / `월정에선 준치지` / `JUNCHI & BEER`

## 1-4. 수익 구조
| 매출원 | 비중 목표 | 마진(가정) | 역할 |
|--------|-----------|-----------|------|
| 준치구이(매장/테이크아웃) | 45% | 원가율 30~35% | 트래픽·체험 |
| 주류·음료(맥주, 제주 막걸리, 하이볼) | 25% | 원가율 25~35% | **이익 레버** |
| 소매 포장(진공팩·선물박스) | 25% | 원가율 35~40% | 객단가·비수기 방어 |
| 굿즈·소스 단품 | 5% | 원가율 40% | 브랜드 확산 |

## 1-5. 비용 구조 (월 고정비 항목 — 금액은 실견적으로 채울 것)
- 임대료·관리비(월정에비뉴 103호 계약 조건)
- 인건비: 오너 + 피크타임 파트 1~2명
- 공과금(전기 — 건조기·냉동고 상시 가동으로 일반 매장보다 높음)
- 포장재, 카드수수료, 배달/플랫폼 수수료(사용 시), 마케팅
- 감가상각: 건조기, 맥반석 구이기, 냉동고, 진공포장기, 인테리어

## 1-6. 손익분기 공식
```
월 손익분기 매출 = 월 고정비 ÷ (1 − 평균 변동비율)
예) 고정비 800만 원, 변동비율 40% → 800 ÷ 0.6 ≈ 1,333만 원/월 ≈ 일 44만 원(30일)
    = 객단가 16,000원 기준 하루 약 28팀
```
(위 숫자는 예시. `cost_model.csv`로 실제 값 대입)

## 1-7. 놓치기 쉬운 핵심 질문
1. **원물이 '살오징어'인가 '대왕오징어(훔볼트)'인가?** — 대왕오징어는 식감·맛이 달라 '준치' 기대치와 다름. 원물·원산지를 숨기지 말고 품질 기준을 정할 것.
2. **비수기(11~2월) 매출 공백** — 소매·온라인(택배)로 메울 계획이 있는가? 택배 판매는 별도 인허가 필요(6번 문서).
3. **냄새·연기 민원** — 상가 건물 내 구이 시 배기 설비·관리단 규약 확인.
4. **주류 판매 가능한 업종으로 신고하는가?** — 휴게음식점은 주류 판매 불가.
