# 6. 인허가 · 리스크 · 오픈 로드맵

> ⚠️ 인허가는 **관할 행정기관(제주시청 위생 관련 부서) 확인이 최종 기준**. 아래는 일반적인 구조이며, 영업 형태에 따라 달라질 수 있음.

## 6-1. 영업 형태별 필요 신고 (일반 구조)
| 하려는 것 | 일반적으로 필요한 것 | 메모 |
|-----------|---------------------|------|
| 매장에서 굽고 **맥주와 함께** 판매 | **일반음식점** 영업신고 | 휴게음식점은 주류 판매 불가 |
| 매장에서 직접 만든 준치를 **매장에서 포장 판매** | **즉석판매제조·가공업** 신고 검토 | 최종소비자 직접 판매 전제 |
| 다른 가게 납품, 대량 유통, 온라인 판매 | 식품제조·가공업 또는 수산물가공업 등록 검토 | 시설 기준·품목제조보고·자가품질검사 등 부담 큼 |
| 통신판매(택배) | 통신판매업 신고 + 위 제조 업종 요건 충족 여부 확인 | 즉석판매제조가공품의 택배 가능 범위 **반드시 확인** |

공통 준비물(일반): 위생교육 이수증, 건강진단결과서(보건증), 임대차계약서, 영업장 시설 기준 충족(작업장 분리·급수·배수 등), 사업자등록.

## 6-2. 표시 의무
- **음식점 원산지 표시**: 오징어는 음식점 원산지 표시 대상 품목 → 메뉴판·게시판에 원산지 명시
- **포장 판매품 라벨**: 제품명·제조일·소비기한·원산지·알레르기·보관법 (4번 문서)
- 원양산·수입산을 '제주산'처럼 오인시키는 표현 금지 — "월정에서 **말린**" 은 가능, "월정 **오징어**"는 오인 소지

## 6-3. 리스크 매트릭스
| 리스크 | 가능성 | 영향 | 대응 |
|--------|--------|------|------|
| 원물가 급등 | 높음 | 높음 | 공급처 2곳, 비수기 비축, 가격 조정 규칙(원물가 ±20% 시 메뉴가 재검토) |
| 원산지 오표시 | 중 | **매우 높음**(과태료·신뢰 붕괴) | 거래명세서 보관, 표기 담당자 지정 |
| 식중독·곰팡이 | 중 | 매우 높음 | 2번 SOP 온도·결로 관리, 영업배상책임보험 가입 |
| 연기·냄새 민원 | 중 | 중 | 후드·덕트, 관리단 사전 합의 |
| 비수기 매출 급감 | 높음 | 중 | 소매·선물·(요건 충족 시) 온라인, 영업시간 축소 |
| 경쟁점 모방 | 중 | 중 | 브랜드·소스 레시피·포장으로 차별, 리뷰 선점 |
| 날씨(태풍·비) | 높음 | 중 | 실내석·테이크아웃 강화, 날씨별 해동량 규칙 |

## 6-4. 오픈 로드맵 (D-60)
| 시점 | 할 일 |
|------|------|
| **D-60** | 월정리 경쟁점 실사, 103호 임대 조건·용도·배기 가능 여부 확인, 관할청 인허가 상담 |
| **D-50** | 원물 공급처 3곳 견적·샘플, 건조기·구이기 견적 |
| **D-45** | 레시피 테스트 1~5차(염도·건조 무게·굽기) → 표준 확정 |
| **D-40** | 브랜드·로고·패키지 시안(AI 활용) → 확정 |

| **D-25** | 영업신고(일반음식점 + 필요 시 즉석판매제조가공업), 사업자등록, 카드단말기 |
| **D-20** | 포장재 1차 발주(무지 박스 + 스티커), 라벨 인쇄 |
| **D-14** | 네이버 플레이스·카카오맵·구글맵 등록, 인스타 계정 티저 |
| **D-7** | 가오픈(지인·주변 상인 시식) → 굽기 시간·동선 수정 |
| **D-Day** | 오픈 — 첫 주 리뷰 이벤트 |
| **D+30** | 판매 데이터로 메뉴 정리(하위 20% 제거), 원가율·수율 리뷰 |
| **D+90** | 전용 인쇄 박스 전환, 온라인 판매 요건 검토, 2호점/납품 판단 |

## 6-5. 다음 단계 (확장)
1. **온라인 선물 판매** — 제조업 요건 충족 후 스마트스토어 "월정 준치 선물세트"
2. **소스 상품화** — 우도땅콩마요를 별도 굿즈로
3. **B2B** — 월정·세화 펍/캠핑장 납품(제조업 등록 필요)
4. **2호점** — 협재·함덕 등 해변 관광 상권 복제(매뉴얼·브랜드 그대로)
