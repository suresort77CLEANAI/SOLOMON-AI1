# 2. 냉동 오징어 → 준치 손질·가공 SOP

> 목표: **매일 같은 맛, 같은 촉촉함(수분), 같은 크기**. 레시피는 수치로 관리한다.
> ※ 아래 시간·온도는 업계에서 통용되는 출발점이며, 사용 건조기·원물에 맞춰 3~5회 테스트 후 확정할 것.

## 2-1. 원물 기준
| 항목 | 기준 |
|------|------|
| 품종 | 살오징어(권장). 대왕오징어 사용 시 별도 메뉴명·표시 |
| 크기 | 마리당 해동 전 약 250~350g (규격 통일 = 가격 통일) |
| 상태 | 선동(선상 동결) 우선, 껍질 변색·냄새·드립(핏물) 과다 품목 반품 |
| 서류 | 원산지 증명/거래명세서 보관 (원산지 표시 근거) |
| 보관 | −18℃ 이하 냉동, 선입선출(FIFO) 라벨 |

## 2-2. 공정 흐름
```
입고검수 → 냉장해동(0~5℃, 12~18h) → 손질(배 가르기·내장/눈/입 제거)
 → 세척(염도 맞춘 물) → 염지(선택) → 물기 제거·펼치기
 → 반건조(건조기) → 냉각 → 소분/진공포장 → 냉동·냉장 보관
 → [매장] 맥반석 구이 → 커팅 → 제공
```

## 2-3. 단계별 상세
| 단계 | 방법 | 핵심 관리 포인트 |
|------|------|-----------------|
| ① 해동 | 냉장 해동. 급할 때 밀봉 상태로 흐르는 찬물 | **상온 해동 금지**(세균·식감 저하) |
| ② 손질 | 배쪽 갈라 펼침 → 내장·먹물·눈·입·연골 제거 | 칼·도마 **수산물 전용**(색 구분) |
| ③ 세척 | 차가운 물(소금 약간)로 핏물·이물 제거 | 과도한 물 접촉은 맛 손실 |
| ④ 염지(선택) | 3% 내외 소금물 10~20분 | **염도 수치 고정**이 맛의 일관성 |
| ⑤ 펼치기 | 꼬챙이/건조망에 다리 펼쳐 겹치지 않게 | 모양 = 상품성(포장 시 중요) |
| ⑥ 반건조 | 식품건조기 저온(약 40~50℃)·송풍, 원물 대비 무게 **약 50~60%** 될 때까지 | **무게로 종료 판단**(시간 아님) |
| ⑦ 냉각 | 실온에서 열기만 빼고 즉시 포장 | 결로 → 곰팡이 원인 |
| ⑧ 포장 | 1미 진공 / 소매용은 진공+탈산소제 검토 | 라벨에 제조일·소비기한 |
| ⑨ 보관 | 단기 냉장(0~5℃), 장기 냉동 | 소비기한은 자체 설정 근거 문서화 |

### 마케팅 포인트로 쓰는 법
- "**월정 해풍 마무리**": 건조기 반건조 후 위생 관리된 망 안에서 짧게 해풍 노출 → 매장 앞 **건조 디스플레이**(볼거리). 단, 실제 위생(먼지·벌레) 관리가 안 되면 디스플레이용 샘플만 걸 것.

## 2-4. 구이(매장) 표준
| 항목 | 기준 |
|------|------|
| 장비 | 맥반석 오징어 구이기 2대(피크 동시 운용) |
| 사전작업 | 오전에 칼집·몸통/다리 분리해 1인분 트레이 대기 |
| 굽기 | 앞뒤 노릇 + 말림 형태 기준 사진을 벽에 붙여 표준화 |
| 커팅 | 가위로 한입 크기, 컵/트레이 담기 |
| 제공 목표 | 주문 → 제공 **3분 이내** |

## 2-5. 품질·위생 체크리스트 (일일)
- [ ] 냉동고 −18℃↓ / 냉장고 5℃↓ 온도 기록
- [ ] 해동 중 원물 냉장 보관 확인
- [ ] 건조 배치별 **투입 무게·완료 무게·시간** 기록 (수율 관리)
- [ ] 이물·곰팡이·이취 검사 후 포장
- [ ] 포장 라벨(제조일·소비기한·원산지) 누락 없음
- [ ] 작업자 위생모·장갑, 건강진단결과서 유효

## 2-6. 수율 관리 (원가의 핵심)
```
수율(%) = 완성 준치 무게 ÷ 해동 전 원물 무게 × 100
마리당 원물원가 = 박스 단가 ÷ 박스당 마리 수
손실률 = 파손·불량 마리 ÷ 투입 마리
```
→ 주 1회 수율·손실률 리뷰. 수율이 떨어지면 원물 공급처나 건조 시간 재조정.
