# 5. 매장 운영 — 준치펍 (월정에비뉴 1층 103호)

## 5-1. 공간 배치 (1층 상가 기준 제안)
```
 [출입구/유리창] ─ 건조 디스플레이 + 선물박스 진열
        │
 [주문·계산대] ─ 키오스크 or 태블릿 POS, 소매 진열대
        │
 [오픈 키친] 맥반석 2대 | 칼집·소분 대기 트레이 | 맥주 디스펜서
        │
 [백룸] 냉동고 · 냉장고 · 건조기 · 손질 싱크(수산물 전용) · 진공포장기
        │
 [좌석] 바 테이블 + 창가석 (회전 빠른 스탠딩/하이체어 위주)
```
- **가공 공간과 판매 공간 분리**(인허가 요건 + 위생). 건물 내 공간이 부족하면 가공은 별도 장소에서 하는 방안 검토(이 경우 업종 신고 범위 달라짐 → 6번 문서).
- **배기·냄새**: 구이 연기용 후드·덕트, 상가 관리단 사전 승인 필수.

## 5-2. 필수 장비
| 장비 | 수량 | 비고 |
|------|------|------|
| 맥반석 오징어 구이기 | 2 | 피크 대응 |
| 업소용 식품건조기 | 1~2 | 일 생산량 기준 선택(트레이 수) |
| 냉동고(−18℃↓) / 냉장고 | 각 1+ | 원물·완제품 분리 |
| 진공포장기 | 1 | 소매용 |
| 수산물 전용 싱크·작업대 | 1 | 스테인리스 |
| 맥주 디스펜서 or 쇼케이스 냉장고 | 1 | 주류 |
| POS·카드단말기·키오스크 | 1 | 간편결제·외국인 카드 |
| 저울(0.1g~10kg) | 1 | 수율·염도 관리 |

## 5-3. 하루 루틴
| 시간 | 업무 |
|------|------|
| 09:00 | 온도 기록, 전날 해동분 손질·염지, 건조기 투입 |
| 10:30 | 완성분 냉각·진공포장·라벨, 구이용 칼집 소분 |
| 11:00 | 오픈 — 디스플레이 세팅, 첫 구이로 '냄새 호객' |
| 13:00~17:00 | 피크: 2대 동시 구이, 준치컵 회전 |
| 17:00~ | 노을·저녁: 세트(준치&비어) 집중 |
| 마감 | 다음날 원물 냉장해동 투입, 재고·수율 기록, 청소 |
> 영업시간은 월정리 상권 유동(낮 관광 + 일몰) 실사 후 결정. 월정리는 밤 늦게 유동이 급감할 수 있음(추정).

## 5-4. 인력
- 초기: 오너 1 + 주말·성수기 파트 1~2
- 가공(오전)과 판매(오후)를 시간대로 분리 → 1인 운영 가능 구조
- 모든 작업 **사진 기반 매뉴얼**(구이 완성 사진, 커팅 사진) → 신규 인력 1일 교육

## 5-5. 마케팅 (월정리 특화)
| 채널 | 실행 |
|------|------|
| 네이버 플레이스 | 오픈 전 등록, 대표사진 = 준치컵 + 바다. 메뉴·가격·영업시간 정확히 |
| 카카오맵·구글맵 | 외국인·젊은층 대응, 영문 메뉴 |
| 인스타그램/릴스 | 굽는 장면 15초 숏폼(소리 포함), "월정에선 준치지" 해시태그 |
| 리뷰 이벤트 | 리뷰 작성 시 소스 1종 or 땅콩 서비스 (플랫폼 리뷰 정책 준수) |
| 숙소 제휴 | 월정·김녕·세화 게스트하우스/펜션에 할인쿠폰 카드 비치 |
| 서핑샵 제휴 | 서핑 강습 후 "준치&비어" 할인 |

## 5-6. AI·자동화 활용
- **메뉴·포장 시안**: 이미지 생성 AI로 시안 다수 → 고객 반응(인스타 스토리 투표)으로 선택
- **리뷰 답글·SNS 문구**: 생성형 AI로 초안 → 사장님 톤으로 수정
- **재고·수율 시트**: 구글시트에 일일 입력 → 원가율·손실률 자동 계산(`cost_model.csv` 기반)
- **수요 예측**: POS 판매 데이터 + 날씨(비·바람) 기록 → 다음날 해동 수량 결정 규칙화
- **다국어 메뉴**: AI 번역(영·중·일) 후 원어민 검수
