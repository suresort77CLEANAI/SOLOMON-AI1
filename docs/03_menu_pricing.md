# 3. 메뉴 · 가격 · 원가

> 가격은 **가정치**(2026-10 기준 추정). 경쟁점 실사·원물 견적 후 확정.
> 참고 앵커: 성산 목화휴게소 준치 1마리 7,000원(2022년 블로그 기준) → 물가·원물가 상승 감안 시 2026년 현재 시세는 그보다 높을 가능성이 큼(미확인).

## 3-1. 매장 메뉴 (준치펍)
| 구분 | 메뉴 | 구성 | 가격(안) |
|------|------|------|---------|
| 시그니처 | **준치 한 마리** | 맥반석 구이 1미 + 소스 1종 | 10,000원 |
| 시그니처 | **준치컵** (테이크아웃) | 구이 1/2미 컷팅, 컵 + 소스 | 6,000원 |
| 세트 | **준치 & 비어** | 준치 1미 + 생맥주/캔맥주 1 | 15,000원 |
| 세트 | 둘이 한 잔 | 준치 2미 + 맥주 2 | 28,000원 |
| 변형 | 준치 버터구이 | 버터·간장·청양 | 12,000원 |
| 사이드 | 땅콩/쥐포 구이 | — | 4,000~6,000원 |
| 소스 | 추가 소스 | 마요간장청양 / 우도땅콩마요 / 한라봉 칠리 | 500~1,000원 |
| 음료 | 제주 맥주, 우도땅콩 막걸리, 하이볼, 탄산음료 | — | 시세 |

**메뉴 설계 원칙**
- 세트를 **기본 선택지**로 노출(메뉴판 가장 크게) → 주류 부착률 ↑ = 이익 ↑
- 메뉴 수는 적게(오퍼레이션 속도 = 경쟁력)
- 비음주 고객(가족·운전자): 준치컵 + 탄산/한라봉 에이드

## 3-2. 소매 포장 라인업
| 상품 | 구성 | 가격(안) | 타깃 |
|------|------|---------|------|
| 준치 1미 진공팩 | 1미 + 소스 스틱 | 9,000원 | 숙소 야식 |
| 준치 3미 선물박스 | 3미 + 소스 2종 + 굽는 법 카드 | 28,000원 | 여행 선물 |
| 준치 5미 패밀리박스 | 5미 + 소스 3종 | 45,000원 | 단체·가족 |
| 소스 단품 | 우도땅콩마요 병 | 6,000원 | 굿즈 |

- 선물박스는 **아이스팩·보냉백 옵션**(+2,000~3,000원)으로 비행기 기내 반입 고객 대응 — 항공사 규정(액체 소스 용량 등) 확인 필요.

## 3-3. 원가 계산 (예시 — 수치 교체 필수)
| 항목 | 준치 한 마리(매장) | 3미 선물박스 |
|------|-------------------|-------------|
| 원물(마리당 가정 3,500원) | 3,500 | 10,500 |
| 가공 손실·전기(10% 가정) | 350 | 1,050 |
| 소스 | 300 | 800 |
| 포장재 | 200 (트레이·컵) | 3,500 (박스·진공·스티커·카드) |
| **변동원가 합계** | **4,350** | **15,850** |
| 판매가(VAT 포함) | 10,000 | 28,000 |
| 공급가(÷1.1) | 9,091 | 25,455 |
| **원가율** | **약 48%** | **약 62%** |

> 📌 해석: 원물가가 마리당 3,500원 수준이면 **준치 단품은 마진이 얇다** → 이익은 **주류 세트**와 **원물 원가 절감(대량·직거래)** 에서 나와야 한다. 원물가가 2,500원이면 단품 원가율은 약 36%로 개선.
> 선물박스는 포장비 비중이 크므로 **박스 단가를 1,500~2,000원대로 낮추는 대량 발주**가 핵심.

## 3-4. 가격 경쟁력 전략
1. **앵커 가격**: 단품 10,000원은 "기준", 세트 15,000원이 "이득"으로 보이게(맥주 단품 6,000원 표기)
2. **원물 원가 절감**: 성수기 전(봄) 대량 매입 → 냉동 비축, 공급처 2곳 이상 비교
3. **수율 개선**: 건조 종료를 무게 기준으로 관리하면 과건조 손실 감소
4. **소매로 재고 회전**: 매장에서 안 팔린 반건조 재고 → 진공·냉동 → 소매/선물 전환
