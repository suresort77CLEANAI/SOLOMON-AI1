# 준치펍 (JUNCHI PUB) — 월정리 반건조 오징어 사업 플레이북

> 냉동 오징어를 직접 손질·반건조해 **'준치'**(제주에서 반건조 오징어를 부르는 말)로 만들고,
> **① 매장(준치펍) 구이 + 맥주** 와 **② 예쁜 포장 소매(선물·여행 기념품)** 두 채널로 판매한다.
>
> 📍 1호점: 제주시 구좌읍 월정리 **월정에비뉴 1층 103호**
> 기준일: 2026-10-10 (가격·원가는 가정치 — 실제 견적으로 반드시 갱신)

## 한 줄 전략
**"목화휴게소의 준치 + 월정리 바다 감성 + 선물 패키지"** —
제주 준치는 이미 검증된 여행 먹거리(성산 목화휴게소, 방송 노출로 유명)인데,
**월정리(카페거리·서핑 상권)에는 '준치 + 맥주' 전문점이 비어 있는 자리**를 노린다.

## 경쟁력 핵심 5가지
1. **원가 우위** — 냉동 원물 대량 매입 → 자체 반건조 → 완제품 매입 대비 원가 30~40%↓ (추정)
2. **속도** — 주문 후 3분 내 제공(사전 칼집·소분, 맥반석 2대 동시 운용)
3. **차별 소스** — 제주 식재료(우도땅콩·한라봉·청양) 시그니처 소스 3종
4. **포장 = 광고** — 들고 다니는 순간 사진이 되는 패키지(준치 컵, 선물 박스)
5. **이중 매출** — 매장(구이+주류, 고마진) + 소매(선물, 객단가↑·재고 회전)
